Kestrel Browser

Version 0.2.0 · Fast. Private. Feather-light.

Kestrel is an independent, privacy-first browser for Windows. A memory-safe Rust core handles privacy, data and platform integration; rendering runs on the Chromium-based WebView2 engine that ships with Windows 10/11, so pages load fast with no extra runtime to install.

  • Network-level ad & tracker blocking (adblock-rust, EasyList/EasyPrivacy/Annoyances)
  • Cosmetic filtering, HTTPS-only upgrades, third-party cookie stripping
  • Anti-fingerprinting (canvas / audio / WebGL / fonts / hardware)
  • Malware host + phishing-lookalike interstitials
  • Everything local: no accounts, no telemetry, no cloud

Engine: WebView2 (Chromium) · UI: Tauri 2 multi-webview · Privacy core: kestrel-privacy (MPL-2.0)
