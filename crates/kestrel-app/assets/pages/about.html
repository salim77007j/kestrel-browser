Kestrel Browser

Version … — MPL-2.0 open source.

An independent, ultra-light, privacy-first browser

Kestrel pairs a memory-safe Rust core with GTK4 and the WebKitGTK rendering engine. It starts fast, idles quiet, and treats tracking as a bug. No legacy engine baggage, no accounts, no telemetry.

  • Brave-class ad/tracker filtering (adblock-rust + WebKit compiled content filters)
  • Fingerprint randomization for canvas, WebGL, audio and hardware
  • Fail-closed TLS, third-party cookie control, WebRTC off by default
  • OS keyring password vault, SQLite local-only data, zero telemetry
